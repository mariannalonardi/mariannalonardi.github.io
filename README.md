# Marianna Lonardi - Portfolio

A modern, interactive portfolio showcasing my work in Interaction Design, Data Visualization, and Digital Experiences.

## 🚀 Live Demo

Visit the live portfolio at: [https://mariannalonardi.github.io](https://mariannalonardi.github.io)

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI (shadcn/ui)
- **Deployment**: GitHub Pages

## 📁 Project Structure

```
src/
├── app/
│   ├── components/     # Reusable UI components
│   ├── pages/         # Page components
│   └── routes.tsx     # Application routing
├── assets/            # Static assets
├── imports/           # Project images and media
└── styles/            # Global styles and themes
```

## 🏃‍♀️ Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/mariannalonardi/mariannalonardi.github.io.git
cd mariannalonardi.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
# Build the project
npm run build

# Deploy to GitHub Pages
npm run deploy
```
